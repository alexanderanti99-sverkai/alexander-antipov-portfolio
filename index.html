Проекты

SverkAI

Веб-сервис для поиска расхождений в актах сверки

Сервис принимает Excel/PDF, извлекает табличные данные, сравнивает позиции, объясняет расхождения и формирует отчет. Для сложных актов добавлен экспертный анализ причин расхождения сальдо с AI-пояснением поверх рассчитанной числовой базы.

  • Python
  • FastAPI
  • pandas
  • PDF parsing
  • Anthropic API
  • Excel export

VK Beat Distributor

AI-assisted automation для продвижения музыкального контента

Инструмент помогает битмейкеру готовить пост, подбирать VK-группы, проверять правила, адаптировать сообщение через AI и вести историю рассылок. Интерфейс учитывает ограничения массовой коммуникации и повторяемые сценарии.

  • JavaScript
  • VK API
  • HTML/CSS
  • Python proxy
  • localStorage
  • AI prompts
